# Python Image Viewer

*(Work in Progress)*

A lightweight, no dependency image viewer built purely with Python's standard library (`tkinter`).

**Currently working on:**

- [x] Initializing the GUI setup
- [x] Adding native file dialogs
- [x] Image rendering logic

---

## Setup & Environment

Since the whole point of this project is to avoid dependencies, you don't need much to get started. Just make sure you have:

- Python 3.x installed: https://python.org
- That's it. Tkinter comes bundled with Python by default

To grab the code and get started:

```bash
git clone https://github.com/hayabusagsxr/no-dep-img-viewer.git
cd no-dep-img-viewer
```

---

# How to Run

```bash
python img-viewer.py
--or
python3 img-viewer.py
```

---

# How it Works

1. Run the script and a 700x500 window will appear
2. Click on a Load Image button
3. Pick an image on your file explorer
4. The image will be shown on the window

---

# Formats that Work
- .png
- .gif
- .ppm
